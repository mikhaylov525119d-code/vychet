# Калькулятор налогового вычета — Юлия Михайлова

Одна страница: клиент вводит зарплату и расходы — видит, сколько вернут, и пишет Юлии.

| Файл | Что это |
|---|---|
| `index.html` | страница калькулятора (дизайн, поля, кнопки связи) |
| `calc.js` | правила расчёта (лимиты 2026 года) |
| `calc.test.js` | проверки расчёта: `node calc.test.js` |
| `CNAME` | появится после покупки домена |

## Публикация на GitHub Pages (один раз)

1. Зарегистрироваться на github.com (бесплатно).
2. Создать репозиторий: «New repository» → имя, например, `vychet` → **Public** → «Create repository».
3. Загрузить файлы: в репозитории «Add file» → «Upload files» → перетащить `index.html` и `calc.js` → «Commit changes».
   (Или через git — команды ниже.)
4. «Settings» → «Pages» → Source: **Deploy from a branch** → Branch: `main` / `(root)` → «Save».
5. Через 1–2 минуты сайт откроется по адресу `https://ЛОГИН.github.io/vychet/`.

### Через git (если удобнее)

```bash
git remote add origin https://github.com/ЛОГИН/vychet.git
git push -u origin main
```

При первом `push` откроется окно входа в GitHub — войти своим аккаунтом.

## Свой домен (общая инструкция)

1. В корне репозитория создать файл `CNAME` с одной строкой — доменом, например `vychet-yulia.ru`.
2. У регистратора домена в настройках DNS добавить записи:

| Тип | Имя | Значение |
|---|---|---|
| A | @ | 185.199.108.153 |
| A | @ | 185.199.109.153 |
| A | @ | 185.199.110.153 |
| A | @ | 185.199.111.153 |
| CNAME | www | ЛОГИН.github.io |

3. GitHub → «Settings» → «Pages» → Custom domain → вписать домен → «Save». Когда появится галочка — включить **Enforce HTTPS**.

DNS обновляется от 15 минут до суток.

## Кнопки связи

При нажатии на MAX, Instagram или Telegram расчёт клиента копируется сам.
- Telegram подставляет текст прямо в поле сообщения (параметр `?text=`).
- Instagram и MAX так не умеют — клиент видит подсказку «вставьте его в чат», и через секунду открывается чат.

## Когда менять правила

Лимиты лежат в начале `calc.js` (`LIMITS`, `CURRENT_YEAR`). В январе 2027 — поменять `CURRENT_YEAR` на 2027 (тогда «3 прошлых года» станут 2024–2026) и проверить, не изменились ли лимиты. После правок — `node calc.test.js`.
